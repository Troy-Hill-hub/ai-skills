# 2026-10-30 实测依据与边界

这是形成技能的真实案例记录，用于判断经验的适用范围。不是下一批任务的固定参数。

## 最终结果

原目录有 130 个原始 PDF，129 个不同 DOI。最终为 126 个原始 PDF 配齐并核验了 SI，共 127 个文档文件；额外 1 文件是 Cheng 2025 的电池数据核对表。Hao 2025 两个原始 PDF 同 DOI，按各自原文名各保留一份对应 SI。原文文件数量、文件名及已归档附件核验通过。

按 DOI 前缀分布：ACS 32、Elsevier 19、RSC 8、Nature 7、Wiley 60 个原始 PDF 已完成。另 3 篇 Wiley 有实际 SI，但大文件或停滞尚未完成归档；用户明确要求停止，所以不再处理。另 1 篇 Elsevier 综述未找到独立 SI，未把它归类为确认无 SI。

**不能写成“130 篇 SI 全部下载成功”。** 附件数、原文完成数、不同 DOI 数是不同指标。

## 有效方法

- DOI 精确匹配与原 PDF / 官方元数据，按出版社分路线。
- 普通直链、出版社官方附件区、PMC 等开放仓储均有成功记录；访问失败后回到用户正常浏览器。
- Wiley 实际附件名和真实 action/downloadSupplement 链接比 DOI 猜文件名可靠。
- 用户普通 Chrome 中已有合法访问；PDF 预览器能打开文件但接口操作受限。用户同意改为直接下载 PDF 后，下载落盘和批量整理有效。
- Windows 用普通 Chrome 一次调用打开少量已确认 URL；不依赖 Page.navigate、临时 profile 或导出 Cookie。传输停滞时，已获准的 Edge 对部分附件有效，但不保证每次有效。
- 接收 Downloads 中正常完成的文件，也识别 `(1)` 副本。先核验再按 SI-原文名复制；不同内容不覆盖，重复 DOI 下载可复用。
- PDF 页解析及首末页渲染、DOCX ZIP CRC、标题/DOI/具体图表内容对应、SHA-256 结合使用。

## 未奏效的方法与改进

| 当时行为/故障 | 更好的复用方式 |
| --- | --- |
| urllib/headless 与内置浏览器反复遇到 403/验证 | 记录失败，不反复重跑；优先已登录正常浏览器 |
| 把 PDF 控制接口失败误认成浏览器没打开 | 检查实际页面、用户截图及文件落盘，区分预览器和网站权限 |
| 多次 Page.navigate、downloadMedia、日志接口超时 | 同一失败机制不反复试；改用宿主允许、已验证的普通链接导航 |
| 旧 Wiley supinfo 路径或 DOI 拼文件名返回 404 | 读取官网实际文件名/href，不把猜测当发现 |
| 短时间大量重发，生成许多重复/未完成下载 | 启动器改为默认 2 个、一批一次调用、记录每个已发 URL；先看增长再定向重试 |
| 只查无后缀的正式文件名 | 同时识别大小写和 `(数字)` 后缀 |
| Python 子进程输出中文解码失败 | 显式 UTF-8；不把乱码/None 当真实下载失败 |
| 只用 SI 标题作门槛 | 保留自动门槛，添加具体 job+SHA+来源的人工证据，不全局放宽 |
| 把第一个附件通过当作整篇完成 | 登记全部文档；主 SI、Checklist 分角色，逐原文核对必需附件 |

## 人工核验的实例

- `adfm74060...docx`：以 Methods 开始；官网对应 DOI 10.1002/adfm.202526995，原文 BN/NaClO4 电解液和 NVPF 合成内容对应。
- `anie202508584...pdf`：Supporting Text 开始；FTEFT、NaTFA、TMSPi 体系与原文对应。
- `anie72430...docx`：没有 SI 标题，但完整论文题名、五位作者、NaPF6/G2/1,3-dioxane 与原文对应。
- `adfm202406764...docx`：仅 Figure S1–S14；原文对 S1 的 19F NMR、S2 的 PF6/DEC/EC/HFPN/PFPN 相互作用、S3 的 LSV 逐项对应。
- `adfm202500258...docx`：仅补充图表；FEC/EMC/TEP 3:2:5、1wt% NaClO4 及表中性能与原文一致。
- `adfm202423841...docx`：Table of Contents 和实验方法开始；FEC/FDMA、PTFB、FF/FFP 标记及 NVPF 测试对应。

这些是特定文件的核对依据，不是可自动接受其他相似文献的“白名单”。技能包没有携带本批审核哈希或用户项目数据；下一次必须对实际文件重做审核。
